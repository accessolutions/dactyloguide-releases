# Dactyloguide — téléchargements

Dactyloguide est un logiciel d'apprentissage du clavier AZERTY, entièrement guidé à la voix,
pour les personnes aveugles ou malvoyantes. Il est développé par Accessolutions.

Ce dépôt ne contient que les versions publiées du programme d'installation.

**[Télécharger la dernière version](https://github.com/accessolutions/dactyloguide-releases/releases/latest/download/Dactyloguide-setup.exe)**

Dactyloguide se met ensuite à jour de lui-même : à chaque nouvelle version, il l'annonce et propose
de l'installer.

Dactyloguide est distribué sous licence GNU GPL. Les sources sont fournies sur demande à Accessolutions.
